# hypr-rice <br>
a arch linux rice made by skitso franic <br>

> [!IMPORTANT]
> for this rice to work <br>
> you need a fresh arch install <br>

## dependencies <br>
> hyprland <br>
> git (to clone this repo) <br>

> [!note]
> this rice installs some apps <br>
> like firefox, fastfetch, flatpack <br>
> it also installs yay and enables multilib <br>

# install <br>
after useing archinstall and rebooting <br>
log into hyprland <br>
open a terminal and run <br>
> sudo pacman -Syu git <br>
and then run <br>
> git clone https://github.com/Skitso-franic/rice <br>
then run the installer <br>
>chmod +X main.sh <br>
sudo ./main.sh <br>
after it installs reboot your computer
